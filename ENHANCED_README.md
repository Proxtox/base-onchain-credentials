# base-onchain-credentials

Verifiable on-chain credentials and soulbound attestations on Base.

## Overview
Starter for building soulbound credentials, achievements, or KYC attestations on Base.

## Tech Stack
- Solidity
- EAS (Ethereum Attestation Service) compatible patterns
- viem

## Getting Started
```bash
git clone https://github.com/Proxtox/base-onchain-credentials.git
cd base-onchain-credentials
npm install
```

## Key Files
- `contracts/OnchainCredentials.sol` - Simple credential issuance and verification
